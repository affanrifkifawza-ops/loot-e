Loot-E Demo Referensi Upload Produk (Standalone, Tanpa Backend)

Form Jual Barang (Referensi Upload)

Halaman demo ini memetakan seluruh kolom tabel produk, aturan validasi upload, guard BR-04, dan kontrak JSON ADR-0001 secara langsung di browser.

* Wajib diisi sebelum submit

Akses Diblokir oleh Aturan BR-04 (Verified Seller Only)

Pengguna dengan is_verified = 0 tidak boleh langsung membuka form upload produk. Pengecekan ini wajib dilakukan di sisi backend PHP (cek ke database dan sinkronkan ke $_SESSION['is_verified']), bukan hanya menyembunyikan tombol di frontend.

Data Wajib di Halaman Verifikasi Seller (sebelum is_verified = 1)

  • no_hp (VARCHAR 20): Nomor HP aktif penjual
  • alamat (TEXT): Alamat lengkap pengiriman barang
  • info_rekening (VARCHAR 100): Bank/E-Wallet untuk pencairan dana Escrow

Masih ada data yang belum memenuhi aturan upload:

    1. Informasi Dasar Produk

    Disimpan ke kolom nama_produk, id_kategori, dan kondisi.

    Tabel: produk
    0 / 255

    Pencarian di search.php mencocokkan kata kunci pada nama produk dan kategori (ADR-0001). Sertakan merek, seri, dan kapasitas utama.

    Backend wajib validasi id_kategori eksis di tabel kategori.

    Wajib dropdown whitelist agar cocok dengan filter Baru dan Bekas% di pencarian.

    2. Foto Utama Produk

    Disimpan ke kolom foto (VARCHAR 255, 1 foto utama, opsional namun sangat disarankan).

    Maks 2 MB

    Belum ada foto dipilih

    Jika kosong, etalase otomatis menampilkan ikon kategori.

    Catatan Implementasi Backend:

    1. Buat folder uploads/produk/ otomatis jika belum ada.

    2. Validasi MIME asli via finfo_file() atau getimagesize().

    3. Rename file unik: uniqid('prod_', true) . '.' . $ext.

    3. Harga, Stok & Opsi Transaksi

    Disimpan ke harga, stok, bisa_nego, dan bisa_barter.

    Default status: tersedia
    Rp

    Format tampil: Rp 0

    Wajib > 0 dan ≤ Rp 2.000.000.000 (batas aman tipe INT signed MySQL).

    Minimal 1 unit.

    Opsi Transaksi Tambahan (Opsional)

    Beli Langsung (Buy Now) selalu aktif. Centang opsi di bawah jika ingin membuka jalur negosiasi atau tukar tambah.

    Mode aktif saat ini: Harga Pas (Beli Langsung saja).

    4. Deskripsi, Riwayat Kondisi & Spesifikasi

    Digabung menjadi 1 payload JSON pada kolom produk.deskripsi sesuai ADR-0001.

    Rincian Riwayat & Kondisi (riwayat)

    Keenam field ini wajib diisi agar tab Riwayat & Kondisi dan ringkasan unit di halaman detail produk tampil lengkap.

    Spesifikasi Teknis Dinamis (spesifikasi)

    Opsional, isi pasangan label dan nilai sesuai kategori barang. Baris kosong otomatis diabaikan.

    Belum ada baris spesifikasi ditambahkan.

    Tambahkan detail teknis seperti VRAM, Socket, Kapasitas, atau Garansi agar tab Spesifikasi terisi.

    Simulasi submit tidak menyimpan data ke database. Hasil validasi dan payload JSON akan ditampilkan di modal.
